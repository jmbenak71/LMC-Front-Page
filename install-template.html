LMC Front Page Builder

A bookmarklet that builds a course front page with buttons linked to your Canvas modules. Version @@VERSION@@.

Install: show your bookmarks bar (Ctrl+Shift+B in Chrome and Edge), then drag this button onto it.

LMC Front Page

If dragging doesn't work, copy the code below. Then create a new bookmark, name it LMC Front Page, and paste the code into the URL field.

How to use it

  1. In Canvas, open any page inside your course, such as the Modules page.
  2. Click the LMC Front Page bookmark. The builder lists every module in the course.
  3. Enter how many buttons you want, or check the modules you want. Then edit the button text, choose red (course content) or gray (course support), and reorder them with the arrows.
  4. Fill in the title, subtitle and welcome text, and check the live preview.
  5. Click Copy code. Edit your front page, open the HTML editor (</>), paste the code, and save.

Good to know

  • The builder only reads your course through Canvas, using your current login. It changes nothing until you paste and save the code yourself.
  • The generated code uses inline styles only, because Canvas removes <style> blocks.
  • Buttons link to /courses/ID/modules/MODULE_ID. Canvas normally updates links in this form during course copy. Check one button in the new course after your first copy.
  • If you add or rename modules later, run the builder again and paste the new code.
